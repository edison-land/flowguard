# Dependency adapters

`dependencies.lock.json` records fetched HEAD commits and content hashes. These were the remote default-branch tips fetched during this implementation, not a promise of future freshness. Updates are explicit: refetch separately, inspect changed instructions/licenses, regenerate and review the lock. Never silently follow `latest` during an audit.

Use `python3 scripts/flowguard.py fetch CACHE` outside the target to clone pinned FULL repositories without hooks/submodules or running installers. Existing cache directories are never overwritten. Use `doctor CACHE` to verify Git commit, required entry and all locked resource hashes. A dirty or mismatched dependency is unavailable, not silently trusted. Missing dependencies do not end the review; disclose fallback and evidence gaps. Cache is not bundled in the deliverable.

For every adapter log: reason selected, mode, loaded paths, input evidence IDs, output artifact, limitations. Native ToB is not tested in this Codex environment. Full independent checkouts retain their notices. FlowGuard's own code/instructions use MIT.
